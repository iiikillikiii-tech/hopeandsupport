# HOPE&SUPPORT - koncept redesignu

Lokální statický návrh modernizace webu `hopeandsupport.cz`. Tento projekt je pouze prezentační náhled pro jednání s majitelem webu a nijak neupravuje produkční stránku.

## Jak náhled otevřít

Otevřete soubor `index.html` v prohlížeči. Návrh používá veřejné logo a banner ze současného webu, takže pro úplné zobrazení je potřeba internetové připojení.

## Co návrh mění

- modernější první obrazovka s jasnou výzvou k daru,
- přehlednější rozdělení obsahu na poslání, programy, projekty, aktuality a kontakt,
- responzivní navigace pro mobil,
- bankovní údaje s možností kopírování,
- jasné označení, že jde o lokální koncept, ne ostrý web.

## Před ostrým nasazením ověřit

- aktuálnost kontaktní adresy a všech fakturačních údajů,
- finální texty v češtině, angličtině a ukrajinštině,
- souhlas s použitím fotografií a grafických podkladů,
- napojení formuláře pro potvrzení o daru,
- analytiku, cookies a přístupnost.
